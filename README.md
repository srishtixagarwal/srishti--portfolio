This package contains Srishti's profile photo and four linked project cards in this order:

1. Formalising Delhi's Weekly Markets
2. Reducing Provider Bias in Reproductive Healthcare
3. League of Legends Early-Game Metrics Using PCA

It also includes the completed Experience, Education, and Skills sections. In this iteration, section spacing is tighter, the education entries run vertically from Bachelor's to Master's, the skills are expanded into three groups, and every **View project** button opens the PDF itself.

## Updating the existing GitHub Pages repository

1. Open the repository that currently hosts the portfolio website.
2. Select **Add file → Upload files**.
3. Open this unzipped package on your computer and drag **all of its contents** into GitHub.
4. GitHub will show the existing files as changed and the new image files as added. This is correct—there is no need to delete the old website first.
5. Enter a commit message such as `Update portfolio content and project links`.
6. Select **Commit changes**.

Upload the **contents of this folder** to the repository root. Do not upload the outer package folder itself.

The repository root must show:

- `index.html`
- `styles.css`
- `script.js`
- `assets/`

Then open **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

The published website normally updates within a few minutes. `index.html` must remain at the repository root.
