# Srishti Agarwal Portfolio — GitHub Pages Package

Upload the **contents of this folder** to the root of your GitHub repository.

The repository root must show:

- `index.html`
- `styles.css`
- `script.js`
- `assets/`

Then open **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

Do not upload the outer `github-pages` folder as a nested folder. `index.html` must be at the repository root.
